
# 🤖 Kanban Task Board – Development Prompt

## Project Overview

Build a modern Trello-style Kanban Task Management Board using React.js and Vite.

The application should provide an intuitive interface for creating and managing tasks across three workflow columns:

1. To Do
2. In Progress
3. Done

The application must follow a state-driven React architecture instead of direct DOM manipulation.

---

## 🎯 Primary Objective

Create a functional Kanban Task Board that demonstrates:

- React component architecture
- State management
- Props
- Event handling
- CRUD operations
- Conditional rendering
- LocalStorage persistence
- Task filtering
- Drag-and-drop interactions

---
